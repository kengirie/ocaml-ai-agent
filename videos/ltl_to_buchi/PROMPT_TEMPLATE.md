YouTube Shorts 用の縦型解説動画を、ずんだもんのナレーションと立ち絵つきでゼロから作ってください。テーマは「{{テーマ}}」です。

## 仕様
- 1080x1920、30fps、H.264 + AAC の mp4。長さは {{目標秒数（例：80〜100）}} 秒程度
- 映像は Python（Pillow など）でフレームを描いて ffmpeg で書き出す。シーンごとに mp4 を作り、最後に連結する
- ナレーションは VOICEVOX で作る。動いていなければ、VOICEVOX Engine の公式 Docker イメージ（voicevox/voicevox_engine:cpu-latest）を起動してよい（起動の許可が必要なら私に聞く）
- 話者はずんだもん（ノーマル）、話速は 1.2〜1.3 倍。原稿はずんだもん口調（語尾「〜なのだ」）にする。ただし「なのだ」を入れすぎて長くなりすぎないようにする
- **各シーンの長さはナレーション音声の長さ＋前後の余白（0.3秒＋0.8秒）で決める**。画面の文字はナレーションの該当部分に合わせて順に出す（VOICEVOX が返すアクセント句ごとのタイミングを使う）
- 長さが目標を超えたら、原稿の意味は変えずに次の順で調整し、何をしたか報告する：余計な読点を削る → 句読点の間（pauseLengthScale）を短くする → 話速を上げる
- BGM はゆったりしたローファイ調をプログラムで作る（途中で無音にならないこと）。ナレーション中は -8dB 下げる。効果音は文字が出るとき（小さく）、強調表示（ポン）、{{成功の場面}}（キラン）、{{失敗の場面}}（低いブー）
- 全体の音量は -14 LUFS 前後
- 見た目：濃紺の背景、日本語フォントは Noto Sans CJK JP（なければ入れる）、色分けは {{色分けのルール（例：用語A＝黄、用語B＝水色、強調＝ピンク、成功＝緑）}}。上部に全体の進行バー、各シーン上部に「n / {{本編シーン数}}」チップ
- 画面の下 380px と右 150px は Shorts の UI と重なるので、重要な文字を置かない
- {{使う記号（例：¬ ∨ ∧ ≡ φ）}} などの記号が文字化けしないか確認する。フォントに無い記号（豆腐 □ になるもの）は使わない
- 画面の右上に小さくクレジットを入れる：「VOICEVOX:ずんだもん」「立ち絵：{{立ち絵の作者・素材名}}」

## ずんだもんの立ち絵
- 立ち絵の画像は添付する（{{背景が透明な PNG ／ 背景つきの画像}}）。背景つきなら背景を抜き、他の絵と重なっていれば切り離す
- 画面の左下に置く。足元は Shorts の UI の下に隠れてよい。ずんだもんの立つ場所（左下）には文字を置かない
- 口パク：口を「開き（元の絵）・半開き・閉じ」の 3 枚に分け、ナレーション音声の音量に合わせて切り替える
- 呼吸のようにゆっくり揺らし、要所（{{跳ねさせたい場面}}）でぴょんと跳ねさせる。最初のシーンでは下から登場させる
- 立ち絵の画像はリポジトリに入れない（作り直すときは手元の画像から再生成できるスクリプトにする）

## 進め方
1. まずナレーション音声を全シーン分作って、長さを表で見せる。読み間違いがないか（VOICEVOX が返すカナ）と、文字を出すタイミングが原稿の区切りに合っているかも確認する
2. 一番情報量が多い瞬間（各シーンの終わり近く）を静止画で書き出して確認し、文字の重なり・はみ出し・文字化け・ずんだもんとの重なりを直す（できれば自動で検査する）
3. 全体を書き出して {{出力ファイル名}}.mp4 として保存する
4. 最後に、映像と音声の長さが一致しているか、音声が途切れたり重なったりしていないか、音量が -14 LUFS 前後かを確認する。口パクが動いているかは、動画からコマを切り出して確認する

必要なソフト（ffmpeg、Python のライブラリ、フォントなど）が足りなければ、インストールしてから進めてください。
